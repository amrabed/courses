## Assignments


### 📝 Assignment 1 - Course Project Abstract

Prepare and submit a 1-page description of your suggested course project. 

The course project is any application that can be hosted in the cloud. Examples include a personal website, a course website, a department or college website, an online coding platform, an online game, an online machine learning tool, etc.

Each project should be completed by only one student during the semester. A small-group project could be allowed as an exception (on a case-by-case basis) depending on the project size.


### 📝 Assignment 2 - Project Report and Demo

Final Report of course project should include the following information:


- Project Title
- Project Team
- Project Abstract
- Description of the end product of the project, e.g. database system, web interface, ...
- Link to online project demo, if available
- Project full description and details
- Specific role of each team member in the project, if team project
- Reason why you chose that project
- Your plan to integrate that project into another one in the future, e.g. graduation project, explaining how
- Cloud platform used for the project
- Other platforms you considered using
- Reason why you ended up using the platform of your choice
- Platform tools used for your project, e.g. Amazon DynamoDB
- Reason why you chose those tools over other tools of the platform
- Any challenges you faced with the selected platform and tools
- What you did to overcome those challenges
- Any other details you find relevant

Project demo can be one or more of the following:




- Online page showing the end product of the project
- Screencast of how you use your end product
- Any other format you find suitable that fully shows the features of your project
