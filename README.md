# Amr Abed — Course Archives

Static archive of lecture slides, problem sheets, assignments, and model answers from:
- **CSE115: Programming Languages (C++)**
- **CSE415: Cloud Computing**
- **CSE422: Computer Controlled Systems**

Built with [Nextra](https://nextra.site/) (`nextra-theme-docs`) and styled with [`@amrabed/ui`](https://github.com/amrabed/ui). Deployed automatically via GitHub Pages at [https://amrabed.com/courses/](https://amrabed.com/courses/).

## Local Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build static bundle
pnpm build

# Preview static export locally
pnpm start
```
